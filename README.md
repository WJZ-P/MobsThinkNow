# 怪物不再愚蠢 / Mobs Think Now

让原版怪物观察、判断和协作，而不是单纯加血、加伤害。仓库现在同时构建
Minecraft Java 26.1.2 的 Fabric Mod 与无需客户端安装的 Paper 服务端插件，并由纯 Java 共享内核保持核心判定一致。

## 当前版本

- 模组版本：`0.1.0-alpha.1`
- Minecraft：`26.1.2`
- Fabric Loader：`0.19.3` 或更高的兼容版本
- Fabric API：`0.155.2+26.1.2`
- Paper API：`26.1.2.build.74-stable`（独立插件产物）
- 可选客户端配置界面：Mod Menu `18.0.0` + Cloth Config `26.1.154`
- 开发客户端光影环境：Iris `1.11.2` + Sodium `0.9.1`（仅 `localRuntime`）
- 构建所需 Java：`25`
- 当前支持的怪物：僵尸家族（僵尸、尸壳、溺尸、僵尸村民）、骷髅家族（骷髅、流浪者、沼骸、干尸）、普通苦力怕、普通蜘蛛、普通末影人、重新启用完整 AI 的原版巨人，以及猪灵、猪灵蛮兵、疣猪兽、僵尸疣猪兽、烈焰人、恶魂、岩浆怪、僵尸猪灵与凋灵骷髅九种下界战斗单位

## Paper 服务端插件

`paper/` 是可独立安装的服务端版本，首批已经使用 Paper 公开的 `MobGoals` 与 `Pathfinder` API 实现真实
GoalSelector 行为，而不是每 tick 强制传送实体：

- 僵尸、骷髅、苦力怕和蜘蛛获得通过 PDC 跨重启保存的难度加权 IQ `1～10`；
- 不覆盖命名牌或其他插件拥有的名字，只维护本插件自己创建的 IQ 名称；
- 僵尸生命不高于 `20%` 或单次受到最大生命 `30%` 的真实伤害时，暂停原版追击并执行最多五条候选的
  有界撤退寻路；距离攻击者达到 5 格或 100 tick 后恢复原战斗 Goal；
- IQ 至少 3 的持剑/斧僵尸与 Fabric 共用 `MeleeWeaponPlanner`：攻击后保持约 2.8 格距离并等待真实武器
  冷却；IQ 至少 6 的斧手会先进行 8 tick 可见前摇，再用碰撞约束跳劈造成默认 `1.5x` 临时攻击倍率，
  地形不适合或准备超过 30 tick 时会降级为地面攻击，不会卡在蓄力状态；
- IQ 至少 4、真实副手持盾的 Paper 僵尸会举盾接近，守候 12～28 tick；正面物理攻击由公共事件适配层
  消解，盾牌会损耗耐久并播放格挡声，但不触发受伤声/红闪。成功格挡后继续守住 2～4 tick，再明确
  放盾反击；正面斧击则造成正常伤害并禁盾默认 3 秒，期间持械周旋 Goal 接管。共享
  `ShieldCombatPlanner` 保证两端的时序、禁用窗口、信号寿命和正面点积边界一致；
- 持弓/弩骷髅被任意当前敌对目标（玩家、铁傀儡等）贴身后，独立的高优先级 Goal 会先放下武器，
  面向逃生路线正向奔跑；IQ 越高越早识别危险、拉得更远，且每只骷髅拥有随难度提高的持久随机速度；
- `CROSSFIRE`/`COMBINED_ARMS` 左右射手会错开半个周期开火；蓄力和释放前均以有界友军胶囊检查
  射界，被队友挡住会取消拉弓并横移换位，贴身时仍由更高优先级的全速脱离接管；
- Paper 持弩骷髅使用共享的装填—瞄准—发射规划：客户端可见举弩与装填声、公开 `CrossbowMeta` 已装填
  状态、速度预判和重力补偿弹道均由公共 API 实现；独行弩手可作战，入队后仍服从会议与错峰射界；
- IQ 7～10 的 Paper 弩手可从副手真实消耗烟花：6～30 格且爆心无队友时才装填；一个全服集中任务以
  默认 48 发硬上限和单弹单次射线驱动可见烟花，命中或超时空爆均不破坏方块，容量/安全不满足则降级箭矢；
- Paper 自然生成的普通持弓骷髅也与 Fabric 共用难度/IQ 加权的 18% 弩手与 25% 烟花弩基础概率；
  `NATURAL/JOCKEY/TRAP` 之外的命令、刷怪笼和插件实体不随机改装，PDC 一次性标记防止重载重复洗职业；
- 苦力怕会预测移动目标、被正面观察或举盾时绕到稳定侧翼、点火后继续追踪预测爆点，并在目标真正
  拉出安全距离时退火；附近苦力怕通过有硬扫描上限的空间哈希预约不同爆炸窗口，冲突者先去侧后方候场；
- IQ 8～10 的 Paper 苦力怕会复用 Fabric 的共享假引爆内核：在真实起爆圈外被盯住或面对盾牌时只闪烁
  `6～8 tick`，随即播放退火声并拉到预测目标侧后方 9 格退出线；全服唯一、最多 64 项的短期退火队列
  消除原版 `swellDir` 残留，玩家中途用打火石接管时则立即移交真实引信，绝不被假动作熄灭；
- 普通蜘蛛会按 IQ 直追、截击或绕到目标侧后，命中后先拉开再接战；IQ 至少 4 的个体可预判移动落点
  跳扑，同一目标一次只授予一只蜘蛛短租约，危险落点会在起跳前被拒绝；
- Paper 在启用蜘蛛战术时精确保存并替换原版跳扑/攻击 Goal，重载、区块卸载和插件关闭时再恢复保存的
  Goal；洞穴蜘蛛仍完整保留原版毒素节奏；
- Paper 混编队伍在 `MOUNTED_BREACH`/`COMBINED_ARMS` 方案下会以共享规划器一对一分配蜘蛛和苦力怕；
  苦力怕用可见跳跃登上蛛背，蜘蛛负责预测投送，并在引信中段抛下载荷后撤离；
- 四种核心怪物会按同一可见目标组成默认最多 20 只的混编小队；任意物种都可凭最高 IQ 当选首领，
  并经历集结、会议、部署、交战和换届。空闲成员继承共享目标，远程、爆破、载具和两翼职责由共享
  规划器冻结；空间查询只访问 `3×3` 桶且最多检查 64 个原始候选；
- 小队会议使用真实 `MobGoals` 导航，目标突然贴近时立即跳过仪式进入交战；成员不会把队友设为目标，
  普通近战/弹射物误伤会被拦截，但苦力怕爆炸仍保留原版友军风险与反制窗口；
- Fabric 与 Paper 的成队查询现共用 `shared` 中的 `BoundedSpatialIndex`：世界/目标组严格隔离，移动实体
  以对象身份 O(1) 换桶，单次只访问九桶并受原始候选硬预算限制；相等快照不会互相覆盖，配置重载会
  以新桶尺寸重建索引；
- `/mtnpaper status|inspect|reload|setiq|spawn|spawnall|assault|selftest` 提供运行诊断、批量生成和真实
  联合兵种冒烟入口；`selftest` 会在临时保活区块生成 IQ 10 的僵尸、弓手、弩手、苦力怕与蜘蛛，先验证
  同队和 `COMBINED_ARMS`，再等待真实 Goal 完成斧手跳劈、弩手可见装填与错峰射击、独行烟花弩碰撞引爆、真实自然出生职业幂等改装、蜘蛛载客，以及独立盾卫探针的
  真实箭矢格挡与延迟反击，最后自动清理；
- `./gradlew.bat paperSmokeTest` 会构建插件、下载并校验固定 SHA-256 的 Paper `26.1.2 build 74`，在随机
  本地端口与全新超平坦世界启动真实服务器，执行上述 `selftest`，只在行为通过且停服退出码为 0 时成功；
- 客户端无需 Fabric、资源前置或协议 Mod。完整安装、能力差异和配置见
  [`docs/PAPER_PLUGIN.md`](docs/PAPER_PLUGIN.md)。

## 僵尸已经会做什么

- **九套职业皮肤**（`zombieProfessionSkins`，默认开启）：普通新兵、剑手、斧手、剑盾卫、斧盾卫、
  工程兵、水桶辅助、岩浆骚扰和持矛空袭兵分别使用保持原版 64×64 UV 与像素颗粒感的独立服装；
  职业编号随实体存档并通过原版同步数据发给客户端，因此临时吃东西、工程技能换手、桶离手或空袭兵
  耗尽火箭时不会闪回另一套皮肤。尸壳、溺尸和僵尸村民继续保留原版辨识度；本地关闭该选项后会
  重新使用原版或当前资源包纹理；
- **可读战术动作**（`zombieBodyLanguage`，默认开启）：组队时首领先抬臂招手召集，开会时会巡视成员、
  分别指向左翼/右翼下令并挥臂发布总攻；成员会转身低声商议、点头确认、摇头质疑和错峰抬臂回应，
  进入交战时按声浪依次抬臂怒吼，受击撤退时前倾冲刺并保持目视前方；剑手在攻击间隙采用胸前
  戒备姿势，斧手则把武器蓄在肩后。战斗状态机还会同步剑士假挥、斧手起跳前下蹲举斧、空中跳劈、
  副手盾击以及工程兵单膝操作 TNT。动作只同步“编号＋世界开始时间”，客户端本地采样全身关键帧，
  不会给每只僵尸每 tick 发送骨骼数据；动作切换、打断与提前结束默认用 `4 tick`
  （`zombieAnimationBlendTicks`，可设 `0～8`）在上一姿势和新姿势之间平滑交叉淡化，真实攻击、盾挡、
  进食、游泳和鞘翅飞行仍拥有更高姿势优先级；
- 每只僵尸拥有会随实体存档的随机智力值 `1～10`，头顶名字末尾显示对应数字，
  例如“僵尸 [7]”；
- 每只僵尸出生时还会固化一条 `0.86～1.14` 的个体声线，并获得速度、最大生命、
  攻击力和追踪距离的永久随机差异；困难模式的分布均值高于普通，普通又高于简单，
  属性修饰符会随实体正常存档而不会在读档时重复叠加；
- 至少 3 只附近的受支持僵尸家族成员、骷髅家族成员、苦力怕、蜘蛛或巨人锁定同一目标时组成临时混编小队；五类怪物
  都能当首领，先取全队最高智力，再由实体 UUID 的随机票从并列最高者中抽出一名；
- 小队先在面向战场的多排半圆席位集合并面向首领“开会”，近战位靠前、远程/辅助位靠后、左右翼
  分列两侧；随后才按命令散开部署。长时间集结时首领会再次招手，但不会每 tick 重复发布动作；
- 默认会议延长为确定性的 64 tick（约 3.2 秒）战术编排：首领巡视全队，成员短暂商议，再依次下达
  左右翼任务。会议开始时协调器只为两名侧翼各执行一次有界原版寻路评估；原路线可达才点头，失败会
  摇头并让首领从缩短侧翼、截断位、正面施压位中发布第一条真实可达的新命令，部署阶段直接复用该结果；
- 会议中的全队注视会随“发言者 → 被点名成员 → 真实阵位 → 敌人”切换；高 IQ 成员更快回应，低 IQ
  成员会稳定慢 1～3 tick。盾卫、剑士、斧手、工程兵和低智力空手成员在等待时拥有各自低频小动作，
  双手持物时会保留盾牌/武器姿势而非穿模。声效只落在关键拍，避免一群怪物同时叫喊；
  进入交战时由首领先吼出进攻命令，最多 20 名成员按两 tick 间隔此起彼伏地应战；
- 首领常驻金色头顶光环；组队期间成员头上显示带颜色的职业名牌
  （首领/施压手/左翼/右翼/截断手/辅助兵/远程手/爆破手/机动坐骑），离队自动恢复原名；
- 首领按智力分配正面施压、左/右翼包抄和截断退路任务；
- **阵容驱动的总攻方案**：协调器在职位重编时只读取本队成员快照，再按首领智力冻结
  `SWARM`、`PIN_AND_FLANK`、`SHIELD_WEDGE`、`CROSSFIRE`、`MOUNTED_BREACH` 或
  `COMBINED_ARMS`。低智力队伍仍会直接群冲；IQ 5 起可用远近牵制，IQ 6 起由盾卫建立正面楔形，
  IQ 7 起可形成双射手交叉火力或蜘蛛—苦力怕机动爆破，IQ 8 且僵尸、骷髅、苦力怕、蜘蛛齐备时
  才进入完整联合兵种合围；
- **可观察目标战术记忆**（`observableTargetTactics`）：只有至少一名成员确实看见玩家时，协调器才会
  累积其举盾、占高、向外拉扯、利用隘口或涉水防守的证据；连续证据达到阈值后才调整总攻方案，
  短暂消失使用迟滞保留，超过 100 tick 才过期。墙后实时位置、速度和隐藏状态不会被读取；
- **战中动态改令**（`dynamicSquadReplanning`）：执行同一 `planEpoch` 阵位的地面僵尸必须连续两次收到
  真实 `Navigation#moveTo=false`，才向首领提交改令请求。协调器最多检查截断位与正面施压位等常数个
  备选，成功或降级后递增计划版本；单成员再进入确定性 `40～80 tick` 冷却，避免坏地形触发 A* 风暴；
- **共享危险位置记忆**（`squadSharedDangerMemory`）：两次确认的战斗路线失败和让射界时双方均不可达的
  位置会写入每队最多 32 条、自动过期的危险黑板；后续会议、部署、战中改令与射界侧移最多采样
  16 个路径节点并绕开对应区域。容量、寿命和采样数均为硬上限，不随世界实体数增长；
- **可观察多目标分工**（`squadThreatDistribution`）：真实攻击者和成员亲眼看见的新敌人才进入最多
  8 条的衰减威胁记忆。每个决策周期至多选择两个次要目标，并按截断手、施压手、远程手等职位亲和度
  分配最多 40% 的合格成员；首领、载具、乘员、已提交苦力怕及至少 60% 全队继续压制原主目标；
- **战地伤员撤离**（`squadCasualtyExtraction`）：交战小队每个决策周期只做一次有界 `O(K)` 扫描，
  选择生命比例最低且低于默认 `30%` 的一名伤员，再优先选择持盾僵尸、否则选择最近的空闲队友担任护卫。
  伤员朝威胁反方向的安全点正向奔跑，护卫横移到两者之间、举盾接敌并利用攻防间隙反击；一次响应默认
  持续 60 tick，结束后冷却 80 tick，避免全队因同一伤员反复改令；
- **蜘蛛战地救护**（`squadSpiderCasualtyTransport`）：没有健康盾卫时，智力至少 6 且未载客的蜘蛛会优先于
  普通无盾步行护卫。蜘蛛先停到伤员旁接应，伤员用至少 3 tick 的真实抛物线跳上蛛背，再由蜘蛛沿撤离
  目的地快速背离威胁；达到 10 格安全距离、恢复、超时、离队或热关闭功能时都会寻找邻接安全点下客并
  精确清除骑乘标记。盾卫始终拥有更高选择优先级，救护蜘蛛运输中也不会回头攻击；
- **蛛网控场协同伏击**（`squadWebAmbushFollowup`）：目标踩中本队蜘蛛登记的临时蛛网时，协调器先把
  当前战斗节拍覆盖为 6 tick `SUPPRESS`，允许骷髅错峰齐射而近战保持阵位；随后统一切入 24 tick
  `COMMIT`，释放近战、载具、射手和爆破位共同追击。目标在口令前挣脱会在 2 tick 容错后取消伏击，
  口令后也只保留最多 8 tick 追击惯性；每队固定冷却 120 tick，且每 tick 只做三次 O(1) 蛛网登记查询；
- **爆点逃生线封锁**（`squadCreeperWebContainment`）：同队苦力怕开始引信后，智力至少 7 的空闲蜘蛛
  会读取苦力怕来向与目标速度，将本轮蛛网优先投到远离爆点的逃生线上。每个新引信最多额外绕过一次
  普通冷却，固定只检查五个候选；进入爆炸圈的蜘蛛仍由更高优先级撤离 Goal 接管；
- **蜘蛛跳扑错峰**（`squadSpiderPounceStaggering`）：同队蜘蛛共享一个 O(1) 空中令牌，第一只起跳后，
  其他蜘蛛继续绕行而非同帧撞成一团。相邻起跳默认至少间隔 8 tick，并一直等待到前一只落地；
  Goal 异常退出时令牌最多 30 tick 自愈，脱队蜘蛛则完整保留单体跳扑节奏；
- **轮换式盾墙**（`squadShieldWallRotation`）：盾楔/联合兵种方案把正面盾卫分配到最多五只一排的独立阵位，
  解决多人堆在同一点的问题；持阵阶段全员举盾，进攻阶段每 16 tick 只开放一名盾卫放盾出击，其余成员
  持续封住正面。大队伍自动换到下一排，并以一次低音量盾击声提示轮换；
- **统一战术活动租约**：近战、远程、跳扑、工程、载具投送、集结、伤员撤离、撤退、空袭、灭火和骷髅紧急脱离
  使用同一优先级仲裁层；`canUse` 只试探，`start` 才占用，运行中每 tick 续租，`stop` 精确释放。

  滑翔姿态。铁矛原版需要 12 tick 才进入动能起伤窗口，所以僵尸会先在约
  10 格外举矛完成准备，再冲向目标；碰撞检测、速度门槛、伤害、击退、耐久和命中声
  全部继续走原版 `KineticWeapon` 管线，没有额外伪造伤害。最后一枚火箭可以完成
  当前攻击航次；弹尽或目标失效后会主动压低航向并着陆，落地后才恢复原版地面长矛
  突刺。客户端同时补齐水平飞行机身、展开鞘翅和双手举矛姿势；
- **智能武器战斗**（`weaponCombatTactics`，默认开启）作用于所有普通持剑/斧僵尸，
  不要求装备来自武装小队。它们命中后先短促后撤侧移，再沿约 2.8 格圆弧周旋，
  武器冷却完成才重新接近；冷却由物品 `ATTACK_SPEED` 计算，例如木/石/铜斧
  25 tick、铁斧 23 tick、钻石/下界合金斧 20 tick、剑 13 tick。智力达到
  `swordFeintMinimumIntelligence`（默认 7）的剑士面对举盾目标时，每个合格攻击轮次有
  `swordFeintChance`（默认 35%）选择佯攻：先以假挥声和前跨制造攻击错觉，但绝不调用伤害结算；
  目标在第 6 tick 后放盾便立刻转为真攻击，坚持举盾则剑士后撤并短暂恢复。判定有 24 tick
  重试节流，不会每 tick 重抽而最终必然触发；
- 斧手有平地与视线时会先建立 1.8～3.3 格起跳距离，然后停步进行完整 **8 tick** 下蹲举斧前摇；
  前摇结束仍会重新检查距离、高差和碰撞，条件失效就取消而非瞬移追踪。真正起跳后保持空中举斧，
  仅在下落阶段命中并获得玩家同款 1.5 倍
  暴击与粒子/声音；水中或明显高低差会立即普通挥击，狭窄地形连续 30 tick 无法
  建立起跳窗口后也会降级。真实挥击帧会覆盖准备姿势，命中、落地、目标丢失或 Goal 停止都会释放
  临时动作，避免模型卡在举斧状态；
- 武装小队还会产出**盾卫僵尸**（`armedShieldChance`，持械者额外配盾，普通
  减半/困难全额）：敌人进入 6 格交战带时优先举盾推进，进入近战距离后停步守候
  随机 12～28 tick（0.6～1.4 秒）。这期间敌人的攻击被盾牌完全挡住后，盾卫会继续
  举盾随机等待 2～4 tick，再明确放盾反击；达到 `shieldBashMinimumIntelligence`（默认 7）的
  盾卫会按 `shieldBashChance`（默认 35%）把这次真实格挡改为副手盾击：前摇第 5 tick 才进行一次
  唯一命中检查，默认造成 2 点伤害和 1.25 强度水平击退，使用盾牌撞击声与横扫粒子，且盾击期间
  `blocksAttack` 会阻止主手武器同时结算。四项参数均可在 Cloth Config 的“武装与武器战术”中调整；
  未触发盾击时仍使用原有延迟武器反击。敌人一直不出手，则在观察期结束且武器
  CD 就绪时主动放盾试探一次。攻击窗口最多 10 tick，攻击与防御互斥；一次挥击后
  保持放盾收招 2～4 tick 才重新举盾，目标躲开则窗口到期收招，不会裸奔追击。
  格挡走原版正面判定；客户端采用玩家同款胸前 `BLOCK` 姿势，盾面图案改为方形像素
  僵尸脸（方头、平直嘴与紫色方眼），不再使用偏圆的骷髅轮廓。原版的盾牌禁用与
  耐久损耗只对玩家生效，因此本 Mod 补了对称机制：**任何用斧头的攻击都会先打掉
  僵尸的盾**并使其短暂无法重举（时长同 `armedShieldBreakSeconds`），当次斧击
  伤害照常结算。持盾者优先被派往正面施压位；撤退 Goal 仍拥有更高优先级。

尸壳和僵尸村民会复用普通僵尸的地面导航、受击撤退、觅食、工程/地形与武器战斗状态机；
溺尸则刻意保留原版两栖导航、入水/上岸与三叉戟 Goal，只接入智力、小队心跳、选举、会议和部署，
避免“统一 AI”反而破坏其水战专长。详细边界见 [ARCHITECTURE_PROPOSAL.md](ARCHITECTURE_PROPOSAL.md)。

## 骷髅已经会做什么

- 每只受支持骷髅家族成员同样拥有可持久化的随机智力 `1～10`，名称末尾显示数字；智力越高，偏好
  射程、贴脸风险识别距离、撤离安全距离、撤离速度、重新寻路频率和拉扯输入越强；
- 原版骷髅家族的持弓成员会把 `RangedBowAttackGoal` 换成 `SmartSkeletonBowAttackGoal`；换成近战武器时
  仍由原版 `meleeGoal` 接管。总开关或 `skeletonAiEnabled` 关闭后，新 Goal 的完整生命周期
  直接委托给原版实现，不会让两个 MOVE/LOOK Goal 同时争抢控制权；
- **对所有当前目标一致拉扯**：玩家、铁傀儡以及其他被骷髅锁定的生物都进入同一套距离
  分带，不再存在“只对玩家后退”的分支；
- **贴脸全力逃跑**（`skeletonEmergencyDisengage`）：当前目标进入智力化触发距离时，独立的
  `SkeletonEmergencyDisengageGoal` 以移动优先级 1 抢占弓术、弩术、避日和避狼行为，立即取消
  当前蓄力并寻找真实逃生路径。原有的智力速度曲线（约 1.29～1.60）现在作为每只骷髅的速度上限，
  再乘一个出生时固化并随实体存档的随机因子：简单 `0.68～1.00`、普通 `0.76～1.00`、困难
  `0.84～1.00`，因此难度越高平均越快，但任何个体都不会超过改动前速度。它与僵尸受击撤退复用
  `EscapePathing` 的陆地落点规划，身体、头部和移动方向都会朝路径下一节点正向奔跑；凝视高度固定为
  自身眼高，不再把脚底路径节点当作观察目标而低头看地。完整路径失败时也会背向威胁向前冲刺，
  不再举弓倒跑。低智力也会逃，高智力会更早启动、拉得更远且更频繁校正路线；触发与结束距离
  始终分离形成迟滞区，不会在边缘反复启停。单次接管最长 80 tick，仍被堵住时会留出 20 tick 给远程 Goal
  正面拉扯反击，再允许下一轮全力逃跑；
- **掩体探头射击**（`skeletonCoverPeeking`）：处于有效远程距离且没有正在拉弓时，无论当前是否
  已被墙体遮住，骷髅都会寻找附近真正可用的墙角。`SkeletonCoverPlanner` 每次只检查四格内最多
  96 个站立格，要求藏身格到目标眼睛的
  碰撞射线被阻断、相邻探头格的射线完全畅通，并且只把评分最高的四组交给原版导航验证；搜索失败后
  等待 2～3 秒再试，不扫描实体或区块。成功后依次执行“进入掩体 → 无视线拉满弓 → 保持瞄准侧移
  到相邻射界格 → 稳定两 tick → 射击 → 保持两 tick 正面射后姿态 → 缩回”。简单难度每轮一箭，
  普通一至两箭，困难二至三箭；目标绕过
  掩体、探头超时、来箭威胁或贴脸状态都会终止这轮计划，其中闪箭和强制脱离始终拥有更高优先级；
- **距离分带与持续走位**：`skeletonPreferredRange` 默认 10 格，再由个体智力缩放到约 8.5～11.5 格。
  目标进入近距带时，弓术 Goal 进入 `KITE` 拉扯：停止导航，始终让头、身体和弓
  面向目标，再使用后退加横移输入拉开距离，期间继续蓄力和射击。它与“放下弓、转身正向奔跑”的
  逃跑是两个独立状态；视线丢失或距离超过约 135%（13.5 格）时重新接敌，其余区域从第一个战斗 tick 起持续
  左右侧移，不再像原版那样原地观察 20 tick 才开始走位。侧移方向每 16～36 tick 才可能变化，
  盾牌目标会获得更强的横向绕射倾向；
- **局部来箭闪避**（`skeletonProjectileDodging`）：每三 tick 只查询自身七格内的箭，并用相对位置、
  箭速和最近交会时间判断轨迹。仅当箭预计在八 tick 内穿过 1.15 格安全半径时，执行 7～10 tick
  的随机侧闪；飞离中的箭、横向明显射偏的箭和八 tick 外的远箭都不会触发。查询走原版局部实体
  分区，不扫描全世界投射物；
- **移动目标预判**（`skeletonPredictiveAim`）：在原版箭速、竖直抛物线和难度散布全部保留的前提下，
  根据目标水平速度加入有限提前量。预测最多向前八 tick、最多三格，默认强度 65%，并按简单 65%、
  普通 82%、困难 100% 再缩放，因此困难模式更会预判但依然保留随机误差。拉弓仍需 20 tick，
  骷髅与流浪者的普通/困难射击间隔仍以原版 40/20 tick 为基准，沼骸与干尸则保留较慢的
  70/50 tick 基准；四者都只增加 ±4 tick 个体抖动来避免整齐齐射，特殊箭效果不变；
- **友军安全射界**（`skeletonFiringLaneReposition`）：每次真正准备放箭时，把目标的可见水平速度加入
  八段保守抛物线走廊，并检查同队实体碰撞箱；爆炸弩另检查目标周围四格危险区。射界连续受阻后，
  地面射手放下武器，最多验证四个左右侧射候选及其原版可达路径；到位、超时或贴脸时立即退出，
  乘坐蜘蛛/巨人的射手则保留弹药等待载具移出遮挡，不会在队友背后无限蓄力；
- **小队射击通道预约**（`squadFiringLaneReservations`）：射手从拉弓或弩进入装填/待发状态开始，按
  五 tick 短租约广播完整八段预测弧线。挡线的地面队友以低于撤退、灭火和载具投送的活动优先级，
  只检查左右各一个可达侧移点；烟花弩还会清空预测落点四格内的友军，开火、失去视线或停止 Goal
  会立即释放租约；
- **弩手与爆炸弩**（`skeletonCrossbows`）：自然生成的普通骷髅按基础 18% 概率再次结合难度和
  智力判定是否把弓换成弩。弩手使用真实的未装填 → 装填 → 已装填 → 射击状态机，并复用距离
  分带、正面拉扯和最高优先级逃跑；客户端补齐双手装填/举弩姿态并阻止原版近战抬臂动画覆盖。
  智力 7～10 的弩手还会按基础 25% 概率携带 3～9 枚带爆炸数据的烟花火箭；距离不足 6 格时
  暂缓爆炸射击并先拉开，有限火箭耗尽后自动改用普通箭；
- **混编小队远程位**：四种受支持骷髅与僵尸家族、苦力怕、蜘蛛、巨人锁定同一目标时进入同一个
  有界空间索引、选举、开会、部署和换届状态机；非首领骷髅家族成员固定在远程位，不会被任何
  物种首领命令贴脸；
- `/mtn status` 会额外显示骷髅弓术/全力逃跑 Goal 安装数、逃跑、掩体计划/探头射击、持弓拉扯、
  来箭闪避、射击、实际使用提前量、弩箭和爆炸烟花射击的累计次数。

当前支持 `minecraft:skeleton`、`minecraft:stray`、`minecraft:bogged` 与 `minecraft:parched`。
只有普通骷髅会在自然生成时随机改装弩；三种变种保留减速/中毒/虚弱箭与原版辨识度。
凋灵骷髅属于下界近战兵种，仍明确留在该家族白名单之外。

## 苦力怕已经会做什么

- 每只普通苦力怕拥有随实体存档的智力 `1～10`。简单、普通、困难的自然出生区间分别为
  `1～7`、`2～9`、`4～10`，难度越高平均战术能力越强；名称末尾显示固定智力数字；
- `CreeperMixin` 只移除原版精确的 `SwellGoal` 与 `MeleeAttackGoal`，安装优先级 0 的小队爆点撤离，
  并换成 `SmartCreeperSwellGoal`（优先级 2）、`SmartCreeperFuseFeintGoal` 和
  `SmartCreeperApproachGoal`（后二者同为优先级 4 且显式互相让位）。总开关或 `creeperAiEnabled` 关闭时，
  接敌与引信完整生命周期直接委托原版实现；优先级 3 的猫/豹猫回避仍会
  正常抢占接敌移动；
- **观察感知与绕盾**（`creeperFlanking`）：智力至少 6 的个体会比较目标水平视线与自己所处方向。
  当玩家正面观察或举盾时，它先前往目标侧后方，而不是沿盾牌正面直冲。左右侧由 UUID 稳定分流，
  多只苦力怕自然从两侧包夹，无需每只实体搜索全部同伴；绕后点不可达时自动降级为速度截击；
- **移动目标截击**：智力至少 4 的个体按目标水平速度计算最多 3.5 格提前点，难度与智力共同提高
  接敌速度，但硬上限为 `1.22`；目标短暂转角后继续前往最近一次直接目击位置；
- **佯爆骗盾与侧移**（`creeperFuseFeints`）：未带电的 IQ 8～10 个体在真实起爆圈外被目标正面注视
  或举盾时，会先停步、注视并让引信上升 `6～8 tick`，产生原版嘶声与闪烁；随后主动退火，播放轻微
  熄灭声并横移到目标视线的侧后 4.5 格外，再交还常规接敌系统寻找真正的爆破窗口。蓄势硬上限远低于
  原版 30 tick 爆炸线，骑乘、带电、外部点燃和已经提交的引信全部跳过；默认冷却 240 tick，并按
  `80%～120%` 给每只个体随机错峰，附近苦力怕不会机械地同步闪烁；
- **移动引信追击**（`creeperMovingFuse`）：保留原版完整 30 tick 引信、首次嘶声、爆炸伤害与
  方块规则，但点火后继续追向目标的有限速度预测点。默认配置速度上限 `1.25`，低智力和低难度
  个体只取得其中一部分；普通 IQ 10 的最高起爆距离约 4 格，带电个体再增加半格；
- **有条件退火**：目标拉出“起爆距离 + 约 3～3.8 格”的安全区后，引信转为回退并重新接敌；
  目标丢失且眼前不存在有效软墙时也会取消早期引信。这样威胁来自追击和位置判断，而不是缩短
  玩家听见嘶声后的反应时间；
- **软墙破门**（`creeperWallBreaching`）：智力至少 8、40 tick 内亲眼见过目标且距离足够近时，
  对射线命中的第一层障碍检查真实破坏速度和爆炸抗性。抗性不高于 20 的泥土、木板、石墙或门可让
  它保持引信完成破口；黑曜石、基岩、无效射线以及关闭 `mobGriefing` 的世界会被拒绝；
- **混编爆破位**：苦力怕与僵尸、骷髅、蜘蛛、巨人共享小队黑板，也可凭全队最高智力当选首领；非首领
  苦力怕标记为爆破手，蜘蛛充足时优先获得载具投送，队友误伤不会让它临时倒戈；
- **小队爆点预约**（`creeperBlastReservations`）：同队普通苦力怕不能同时对同一目标或重叠区域提交
  引信；候补者会在首枚预测危险圈外的固定侧翼等待，而不是继续贴近后被队友提前炸死。预约每 tick
  随预测爆心续期并重新检查冲突；外部点燃属于不可撤销事实，可并存但会迫使仍可退火的普通提交者让位；
- **引信后小队疏散**（`creeperSquadEvacuation`）：同队苦力怕开始嘶鸣后，非爆破成员会放下远程武器并
  沿真实可达路径退出原版伤害候选圈；普通和带电个体分别使用约 `6.75`、`12.75` 格触发半径，并保留
  一格结束迟滞。撤离会在苦力怕当前脚下与预约预测爆心中选择对自己更危险的一处，既能提前避开冲锋
  落点，也不会因苦力怕被墙挡住而漏掉眼前爆炸。协调器只维护正在引信的爆点 ID，查询为 O(P)；蜘蛛
  不会逃离自己背上的爆破载荷，正在提交的苦力怕也不会因另一个爆点反复取消自身引信；
- `/mtn status` 会记录四个 Goal 的安装量、绕后、截击、佯爆/完成/骗盾、移动引信、破墙提交、主动退火、队友疏散，
  以及爆点预约成功、冲突、释放和当前活跃数。

当前只改造 `minecraft:creeper`。完整引信声音、猫克制、玩家拉远和坚固方块都是明确反制窗口；
本版本不修改爆炸半径、伤害或原版生成数量。

## 蜘蛛已经会做什么

- 每只普通蜘蛛拥有随实体存档的智力 `1～10`，自然出生区间同样随难度从 `1～7`、`2～9`
  抬升到 `4～10`，名称末尾显示固定智力数字；
- 每次完成出生流程时另有总计 `5%` 的速度药水特质：`4%` 获得带可见粒子的永久速度 I，`1%`
  获得永久速度 II；若原版或其他 Mod 已给出同级或更强速度效果则原样保留；
- `SpiderMixin` 精确替换原版 `LeapAtTargetGoal` 和私有 `SpiderAttackGoal`，并安装爆点撤离、集结、
  伤员撤离、临时蛛网、苦力怕投送、普通队友载运、优先级 3 的 `SmartSpiderPounceGoal` 与优先级 4 的
  `SmartSpiderCombatGoal` 共八个 Goal；
  总开关或 `spiderAiEnabled` 关闭时，个人战斗 Goal 委托原版生命周期。爬墙仍使用原版
  `WallClimberNavigation`；
- **预判跳扑**（`spiderPredictivePounce`）：智力至少 4 的蜘蛛可在 `2.5～7` 格内根据目标水平速度
  预测落点，困难和高智力个体跳扑更果断，但水平速度硬上限 `0.60`、垂直速度最高 `0.46`；
  加入小队后共享跳扑令牌，避免同时升空互撞或一起遮挡骷髅射线；
- **观察感知与侧袭**：智力至少 6 的蜘蛛发现目标正在看向自己或举盾时，会前往稳定的侧后点；
  智力至少 4 的普通追击也会计算有限移动提前量；
- **命中后拉扯**（`spiderHitAndRun`）：智力至少 5 的蜘蛛命中后继续注视目标，向侧后方退出到
  下一次跳扑距离，再重新进攻；它与全力逃跑不同，整个阶段都保留进攻朝向；
- **预判临时蛛网**（`spiderPredictiveWebTrap`）：智力至少 7 的空闲蜘蛛在目标即将穿过的落脚点具有
  可达承重面且没有阻挡时，会先做 8 tick 可见蓄势，再放置一格临时蛛网；默认每只蜘蛛冷却
  `140～260 tick`，每个维度最多保留 128 个陷阱。该逻辑尊重 `mobGriefing`，到期、区块卸载或服务器
  关闭时恢复原方块，若玩家已替换该位置则保留玩家修改；同队协调器还会验证蛛网所有者 UUID，只有
  本队蜘蛛的真实临时蛛网才能触发“先齐射、再冲锋”的控场连招；
- **蜘蛛—苦力怕投送**（`spiderCreeperCoordination`）：蜘蛛与普通苦力怕在附近且拥有相同目标时，
  优先进入会合阶段。靠近后蜘蛛会停步接应，苦力怕先用至少 `3 tick` 的真实抛物线跳到蜘蛛背上，
  再通过原版骑乘关系合体；登乘后苦力怕会立即转头并持续注视共享目标。此时苦力怕被定义为
  “载荷”而非驾驶者，所以蜘蛛的 MOVE/LOOK/JUMP 控制保持工作；实体 tick 顺序造成的前 20% 早期
  引信会先退回再合体，外部强制点燃或中后段引信则保持原状态；
- 合体后蜘蛛按双方较高智力预测目标位置。每组先在配置值的 `88%～100%` 抽取自己的速度上限，
  再从 `1.10` 向该上限插值；默认配置最高 `1.40`，因此同场组合快慢有别且峰值更低。
  只有进入苦力怕自己的起爆距离后才把引信方向切为正，并在最终冲锋阶段追加一次携弹跳扑；
- **混编机动坐骑**：普通蜘蛛会参加同目标小队，并由协调器做一对一乘员分配；优先投送苦力怕，
  其次快速换位骷髅，最后搭载近战僵尸。小队交战后，乘员先用至少 `3 tick` 的真实跳跃登背，蜘蛛
  再按同一随机速度上限执行总攻命令。机动爆破方案会先绕到目标侧后约 6～7 格的 staging point，
  到位后才转入最终冲锋；载着骷髅时则停在左右交叉射界并持续随目标重定位。载具蜘蛛不再叠加
  小队通用 `+10%` 移速，避免突破 `1.40` 默认峰值；未分到乘员的蜘蛛继续使用自己的侧袭、跳扑和拉扯战术；
- 合体仍保留苦力怕原版完整 30 tick 引信、嘶声、爆炸半径和伤害。目标在引信早期拉开超过
  “起爆距离 + 6 格”时，载具会先退火再追；目标失效时双方分离并清理预约；
- **载具路线净空评估**（`spiderTransportRouteAssessment`）：登乘前和投送重寻路时最多采样原版路径
  的 16 个节点，按蜘蛛与乘员合体后的宽度、高度检查窄路、低顶和超过 2.5 格的危险落差；引信提交前
  连续两次失败会在八个邻接候选中寻找有承重、无碰撞的安全卸载点，并冷却 80 tick。引信已经提交后
  不会突然把苦力怕丢下；分配路线预检失败则冷却 40 tick，避免每 tick 重建相同路径；
- 配对不是全局互扫：每只蜘蛛每 `10～20 tick` 只查询配置半径内的实体，单次最多评估 32 个候选；
  每只苦力怕只有一条 60 tick 可续租预约，因此多只蜘蛛不会同时争抢同一载荷；100 tick 内无法
  完成会合时会释放载荷，让双方恢复各自战斗；
- `/mtn status` 会额外记录六类总攻方案、交叉火力、机动爆破、完整联合兵种方案，以及蜘蛛 Goal
  安装、绕侧、跳扑/小队错峰/活跃令牌、命中后拉扯、蛛网蓄势/放置/到期恢复、配对搜索/候选检查、
  成功合体、侧后集结和移动火力平台次数。

当前只改造 `minecraft:spider`；洞穴蜘蛛继续使用原版毒素节奏。玩家可以利用配对会合窗口、猫对
苦力怕的克制、引信嘶声、早期拉远和坚固掩体进行反制。

## 末影人已经会做什么

- 每只普通末影人拥有随实体存档的智力 `1～10`，简单、普通、困难难度的自然区间分别为
  `1～7`、`2～9`、`4～10`，名称末尾显示固定智力数字；
- **四种持久职业**：职业编号通过 `SynchedEntityData` 同步给客户端并写入实体存档，重进世界不会换职。
  自然生成时会优先尊重其他模组已经放入的剑、盾或动能长矛；空手个体再按难度、智力和维度分配
  裂隙猎手、虚空盾卫、虚空枪骑或苦力怕使者。末地主场的精英职业概率额外增加 `12%`，总概率
  仍限制在 `88%` 以内；
- **裂隙猎手**手持铁剑，会在 `5～18` 格且视线成立时，从固定上限的安全候选中尝试换位到目标侧后方；
  IQ 至少 7 的猎手命中后还有 `42%` 概率闪退约 6.5 格，形成“切入—挥砍—脱离”的短循环；
- **虚空盾卫**手持石剑和一面带紫青虚空纹章的真实原版盾牌。进入 12 格开始举盾，贴近后随机观察
  `14～30 tick`；真实格挡成功会再保持 `2～4 tick`，随后明确放盾、做 2 tick 反击前摇并追击。
  攻击和防御不会同时发生；斧类攻击仍可通过原版 `BLOCKS_ATTACKS` 组件禁用盾牌；
- **虚空枪骑**手持铁长矛，复用原版 `SpearUseGoal` 的动能蓄力、冲锋和命中语义；每轮冲锋前只做
  一次有限侧后换位，再从 12 格战术距离发动突刺，而不是复制一套与原版脱节的伤害代码；
- **苦力怕使者**保持双手空闲，并独占下面的苦力怕投送 Goal。这样持剑、持盾和持矛职业不会在战斗
  中突然把武器语义切换成抱实体；
- **敌对机制完全沿用原版**：本模组不主动给末影人寻找玩家，也不改变凝视、雕刻南瓜伪装、受击、
  持续愤怒和目标丢失规则。只有原版已经让它敌对一名存活的非创造/非旁观玩家，且双方相距至少
  5 格时，苦力怕使者的额外投送 Goal 才有资格运行；抵达投放点以前，玩家重新直视它时仍优先服从原版凝视
  停步。抵达以后本轮投送已经提交，不会因为苦力怕恰好出现在准星附近而中断放置和撤离；
- **局部预约苦力怕**：默认在 16 格配置半径内搜索尚未乘坐、未被点燃且引信未明显推进的普通
  苦力怕，低智力个体只使用部分半径；每轮最多检查 24 个候选。预约与蜘蛛投送共用同一条 UUID
  租约，因此蜘蛛和末影人不会抢走同一只载荷；
- **真实抱取实体**：末影人靠近后让苦力怕以原版乘客关系 `startRiding` 登乘，而非生成视觉替身。
  自定义乘客挂点把苦力怕脚部放到末影人腰胸前方，乘客不会取得 MOVE/LOOK 驾驶权；原版乘客树
  负责服务端同步、区块保存和随传送移动；
- **实体抱持动画**：客户端从真实乘客关系写入 `EndermanRenderState`，再把原版“手持方块”的双臂
  语义扩展为更前伸、略内收的环抱姿态。苦力怕仍由自己的原版渲染器绘制，所以材质、闪白、名称、
  资源包和其他正常实体效果不会被复制模型破坏；
- 抱稳 `8～17 tick` 后，每轮只抽取一次投送方向：默认 `80%` 选择玩家当前水平视线正前方的
  `±18°` 窄视锥与近身距离，并强制确认玩家到载荷的直线可见；剩余 `20%` 保留后方奇袭。地形
  回退候选继续保持同一侧，不会把一次已抽中的正面展示偷偷换成背刺；
- 抵达后保留约 8 tick 的抱持展示，再检查地基、两格净空、流体、碰撞和垂直落差，放下苦力怕并
  调用原版 `ignite()`。末影人会在载荷旁随机停留 `5～8 tick`，随后尝试传送到至少 12 格外；若
  当前候选失败则每 2 tick 重试，20 tick 后扩大单轮候选数，同时实际向远离载荷的方向跑动。即使
  玩家此时死亡、切换模式或目标引用消失，已经点燃的载荷也不会让撤离状态机挂机；
- 爆炸引信、声音、伤害、方块破坏和猫克制仍由苦力怕原版规则决定；
- 成功投送默认基础冷却 15 秒，并按智力略微缩短后加入随机错峰。目标失效、载荷死亡、预约超时、
  玩家凝视或安全传送失败都会清理租约；尚未投出的载荷会下车并保持退火，不会凭空强制爆炸；
- 四种职业各有独立 `64×32` 皮肤；客户端在原版末影人渲染器上追加原版 `ItemInHandLayer`，因此剑、
  长矛和带旗帜图层的盾牌是真实装备而非烘焙进贴图。手持原版方块时临时隐藏手部装备渲染，避免
  方块、武器和双臂互相穿插；
- `/mtn status` 会记录末影人 Goal 安装、局部搜索、候选检查、成功抱取、投送传送和点燃，以及职业
  传送、盾牌格挡/反击命中、长矛冲锋和职业近战命中次数。

当前只改造 `minecraft:enderman`，不把它加入现有五类混编小队；末影人手持原版方块时也不会
启动实体投送，避免两套手持语义冲突。

四职业配色、UV 约束、可复现生成命令与测试入口见
[`docs/concepts/ENDERMAN_PROFESSION_ASSETS.md`](docs/concepts/ENDERMAN_PROFESSION_ASSETS.md)。

## 巨人僵尸已经会做什么

- 原版 `minecraft:giant` 只有属性与模型、没有任何 Goal。本模组为它补齐目标选择、游荡、游泳、
  近战、混编心跳和队友误伤过滤，并赋予随存档保存的智力 `1～10`；默认最大生命 `160`、攻击
  `14`、基础移速 `0.16`，同时保留高护甲、70% 击退抗性与重击击退；
- **可读近身格斗**：巨人进入七格战圈后不再用原版瞬时挥拳，而会按距离、附近敌人数、目标防御、
  智力和空闲手臂选择单手横扫、快速掌击、左右脚踩踏、正蹬、抓取投掷或双拳砸地。横扫覆盖宽前弧，
  正蹬优先破解贴脸举盾，踩踏可以在双手抱有载荷时使用，双拳砸地要求两手完全空闲并优先处理人群；
- 前摇初期每 tick 最多修正 `14°`，所有动作都会在命中前数 tick 锁死攻击方向；侧闪成功后巨人会
  真实挥空。横扫、掌击、正蹬、抓取和砸地还带分段向前踏步，每个小位移都先检查完整碰撞箱与前方
  落脚面，因此不会磁吸转身、穿墙或沿动作曲线冲下悬崖；
- 智力 `7～10`、单体近身且至少一手空闲时可以抓取。接触帧只结算一次轻伤，随后目标成为固定掌心
  乘客，被抬起、后拉并以水平 `1.28` 的动量抛出；抓取/乘客槽不复用小队载荷 UUID。期间单次实际
  掉血达到 `max(6, 最大生命×5%)` 会打断动作、安全放下目标，并让巨人硬直 `20 tick`。释放时会同时
  检查下车前后的碰撞箱，掌心被墙体或天花板堵住时沿攻击方向、手臂外侧和巨人脚边安全环改选落点，
  不再把玩家塞进方块；
- 每个动作都有完整前摇、唯一命中帧和后摇；服务端仅在该命中帧查询一次有界范围、过滤乘员/
  同队成员和墙后实体，再结算动作独立的伤害、水平击退与向上抛力。客户端用同一同步时间轴驱动
  手臂、躯干和腿部关键帧，并在命中时播放横扫/重击声、地面碎屑和冲击粒子，不会出现动画尚未
  碰到玩家就提前扣血或一段动画重复伤害；
- 普通僵尸完成真实出生流程后有概率延迟替换成巨人。普通难度默认 `1%`，简单为该值的 `40%`，
  困难翻倍，和平为零；指令、读档、维度旅行、转化与骑士生成不会递归触发。替换安排在实体入世后的
  维度 tick 末，避免在 `ENTITY_LOAD` 回调内递归修改实体管理器；巨人 12 格碰撞箱放不下时保留原僵尸；
- **混编重装平台**：巨人同样参加统一选举，智力最高时可以当首领。协调器先为每个巨人分配一名
  普通骷髅远程手。射手在交战后先跳向巨人放低的右掌，随后由巨人连续举到肩部、短暂停顿，再
  平滑送到 12 格高的头顶；不再从低空直接瞬移登顶。乘客不会取得 MOVE/LOOK 驾驶权，登顶后
  原有弓/弩 Goal 继续从高处射击；
- **左右手独立载荷**：分配射手后，协调器再以苦力怕优先、僵尸其次的顺序轮转预约最多两名载荷，
  同一成员不会同时被蜘蛛和巨人争抢。每只手用独立 UUID、运行时实体 ID 与阶段机固定身份；一侧
  死亡、下车或迟到只清空该侧，另一侧既不会换手，也无需等到双手装满。右手接射手期间左手仍可
  独立收取载荷；正在抓取的动作手也会被统一仲裁器锁定，旧乘客迁移和高优先级投送 Goal 都不能
  中途抢手、取消抓取；
- 每只手各自经历会合、伸手接取、持握、`12 tick` 蓄力、挥臂离手和 `10～16 tick` 恢复。两只
  已就绪的手至少错开 `10 tick` 离手，但较远的第二名候选不会阻塞第一只手。客户端同步完整阶段，
  对应播放接取、后拉瞄准、单手投掷与自然收臂；真实载荷挂点同步跟随掌心轨迹，离手帧不会跳位；
- 弹道按目标水平速度做有限提前量，水平速度硬上限 `1.30`；苦力怕离手时调用原版 `ignite()`，
  僵尸则保留目标并借抛物线快速近身。目标失效或功能关闭时，尚未投出的载荷会安全下车而非被强制点燃；
- 配置页可调整普通难度生成率、生命、伤害、移速，并可分别关闭头顶射手/双手投送和可读近战动作；
  关闭新近战时会自动回落到普通单体挥拳。`/mtn status` 记录出生替换、射手登顶、载荷拾取、
  两类抛投以及近战动作/命中/受击目标、成功抓取/抛出、受击打断和安全释放改位次数。

## 下界生物已经会做什么

- **猪灵战线**：猪灵弩手按实体 ID 固定分到左右射击通道，距离过近先后撤并横移；近战猪灵从
  目标侧后方接敌，猪灵蛮兵则压住中线。控制器只在原版 Brain 完成本 tick 后写入
  `WALK_TARGET` 与 `LOOK_TARGET`，交易、金甲判定、疣猪兽数量、僵尸化恐惧和既有仇恨仍由原版决定；
  每只猪灵用 O(1) 散列选线，不会互相全量扫描而退化为 O(N²)；
- **烈焰人空中散兵**：在默认约 10 格外盘旋，目标贴近时主动拉开；先进入可见充能，再按简单、
  普通、困难分别发射 2、3、4 枚小火球。目标速度会加入有上限的提前量，散布、碰撞、声音与
  原版火球伤害保持不变；关闭配置后 priority 4 的原版攻击 Goal 会自动恢复；
- **恶魂机动炮兵**：玩家垂直索敌带从原版 4 格扩到 16 格；仍保留 20 tick 充能声光，开火时对
  移动目标有限预判，并在每次射击后沿目标外圈换炮位，避免悬在原地持续对射；
- **疣猪兽冲锋**：成年疣猪兽与僵尸疣猪兽会在 6～13 格直线上先用 12～16 tick 蓄力，逐段检查
  地基、净空与悬崖后只施加一次真实冲锋冲量；命中只结算一次，随后进入固定恢复期。原版繁殖、
  畏惧方块、族群判断与僵尸疣猪兽的广泛敌对关系均不改写；
- **岩浆怪预判跳扑**：每次原版真实离地时冻结一次短期预测点，只增强该次跳跃的水平分量；尺寸、
  难度与配置共同限制速度，原版垂直跳高、跳跃间隔和接触伤害不变；
- **僵尸猪灵战士**：原版中立仇恨、群体警报和金矛状态机保持不变；持矛者固定为长矛手，持剑者
  分为狂战士与战吼者。狂战士在 3.2～7 格先用 6 tick 怒吼蓄力再短突进，命中后不再一直粘住
  碰撞箱；战吼者则用更长的侧后撤窗口重新找角度；
- **凋灵骷髅战士**：决斗者命中后长时间面向目标拉开，收割者使用 8 tick 可读前摇突进；困难模式
  提高稀有咒火弓手占比。弓手保留原版燃烧箭、凋灵骷髅敌我关系与射击节奏，只增加有限移动预判；
- **21 种持久职业**：猪灵分为弩手、先锋、指挥官；烈焰人分为空中散兵、齐射大师、熔核近卫；
  恶魂分为机动炮兵、远程观测手、攻城破坏者；疣猪兽/僵尸疣猪兽共享冲锋手、壁垒、破阵者；
  岩浆怪分为猎手、伏击者、熔火泰坦；僵尸猪灵与凋灵骷髅各有三种独立职业。困难难度提高精英占比，职业会真实改变编队移速、偏好射程、
  弹幕规模/前摇、恶魂预判/换位/爆炸威力、冲锋蓄力/冲量或跳扑速度，而非只换一个名字；
- **30 张差异化像素贴图**：职业编号通过实体同步数据发给客户端并写入存档，临时换手、攻击阶段和
  重新登录都不会随机变脸。猪灵蛮兵拥有独立版本，疣猪兽与僵尸疣猪兽分别绘制，恶魂普通脸/蓄力脸
  成对提供，新增僵尸猪灵与凋灵骷髅各三张；幼年猪灵、幼年僵尸猪灵与幼年疣猪兽继续使用原版专用 UV。配置里可只关闭职业贴图而保留战术差异；
  完整视觉矩阵和可再生流程见 [`docs/concepts/NETHER_PROFESSION_ASSETS.md`](docs/concepts/NETHER_PROFESSION_ASSETS.md)；
- 下界派系没有被硬塞进主世界混编小队：猪灵、疣猪兽、僵尸猪灵和凋灵阵营继续遵循原版敌我关系；
  新增亡灵职业只替换自身战斗 Goal，不会让两个敌对阵营错误结盟。

## Alpha 限制

- 侧袭点目前使用轻量几何计算，复杂建筑和高低差仍由原版寻路决定；
- 蜘蛛运输组会有界检查窄门、低顶和危险落差，但仍复用原版爬墙寻路；复杂垂直转角找不到安全卸载点时
  会暂时保留乘员而不是把实体塞进墙内；
- 巨人需要 12 格实体净空，头顶射手还会再占约两格；狭窄洞穴里自然替换会保留原僵尸，已有巨人也
  不会为了载荷强行穿墙；
- 智力会持久化，小队、首领和命令是临时战斗状态，不持久化到存档；
- 职业名牌使用本模组语言键；未安装本模组的原版客户端会显示英文回退文本；
- 材料槽只保留一种方块类型，完整立柱与玩家追击墙不会自动拆除。后续再扩展
  跨障碍搭桥、拆门、混合材料和战后清理；
- 持矛空袭目前只寻找半径 7 格内的露天起飞点；长期封闭洞穴中的持矛僵尸会保留
  火箭并等待出现可用起飞空间，不会为了强行出手切回地面攻击；
- 工程兵的战术 TNT 使用原版爆炸和 4 秒引信；当三个开关/规则均开启时会真实伤害生物并
  改造可破坏地形。随机技能使用的 TNT、水桶、岩浆桶与打火石目前是职业资源而非库存，
  不会耗尽；可分别关闭 `engineerTntSkill`、`engineerFluidSkills` 或
  `engineerIgnitionSkill`；
- 尚未完成大规模实体压力测试和网易环境适配验证；
- 配置字段和数值在正式版前可能调整。
