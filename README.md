# 怪物不再愚蠢 / Mobs Think Now

让原版怪物观察、判断和协作，而不是单纯加血、加伤害。当前版本是面向
Minecraft Java 26.1.2 + Fabric 的首个可玩原型。

## 当前版本

- 模组版本：`0.1.0-alpha.1`
- Minecraft：`26.1.2`
- Fabric Loader：`0.19.3` 或更高的兼容版本
- Fabric API：`0.155.2+26.1.2`
- 可选客户端配置界面：Mod Menu `18.0.0` + Cloth Config `26.1.154`
- 开发客户端光影环境：Iris `1.11.2` + Sodium `0.9.1`（仅 `localRuntime`）
- 构建所需 Java：`25`
- 当前支持的怪物：原版普通僵尸、原版普通持弓骷髅

## 僵尸已经会做什么

- 每只僵尸拥有会随实体存档的随机智力值 `1～10`，头顶名字末尾显示对应数字，
  例如“僵尸 [7]”；
- 每只僵尸出生时还会固化一条 `0.86～1.14` 的个体声线，并获得速度、最大生命、
  攻击力和追踪距离的永久随机差异；困难模式的分布均值高于普通，普通又高于简单，
  属性修饰符会随实体正常存档而不会在读档时重复叠加；
- 至少 3 只附近僵尸锁定同一目标时组成临时小队，最高智力者成为首领；
- 小队先向集结点靠拢并面向首领“开会”，随后按命令散开部署；
- 开会有“剧场感”：首领以自己的低沉声线训话并冒怒气云，成员轮流应声冒音符；
  进入交战时由首领先吼出进攻命令，最多 20 名成员按两 tick 间隔此起彼伏地应战；
- 首领常驻金色头顶光环；组队期间成员头上显示带颜色的职业名牌
  （首领/施压手/左翼/右翼/截断手/辅助兵），离队自动恢复原名；
- 首领按智力分配正面施压、左/右翼包抄和截断退路任务；
- 包抄成员会实时读取目标的视线方向：被盯住时继续沿弧线绕后，没有被注视时
  则直接突袭目标当前位置；不再设置专门承担伤害的诱饵职位；
- 组队期间全员获得默认 +10% 的临时移速加成（`squadSpeedBonus`，离队自动移除、
  不写入存档）；
- 首领死亡或离队后，存活成员会自动选出新首领并短暂重组；
- 玩家贴近或被小队目标攻击时，小队会立刻转入交战（日晒着火等无关伤害
  不再打断会议）；
- 丢失视线后只搜索最后目击位置，不读取墙后玩家的新位置；
- 组队采用每维度统一的有界空间索引，不再由每只僵尸互相范围扫描；
- 不增加生成数量，也不做全员统一的数值膨胀；出生个体属性围绕难度均值上下浮动。
  普通空手僵尸保持原版攻击节奏，剑/斧僵尸改为读取武器自身的攻击速度组件；
- 同一小队的僵尸**互相误伤不转移仇恨**（`squadIgnoreFriendlyFire`）：被队友
  打到也继续合攻原目标；玩家和队外敌人的攻击照常触发反击警报；
- **受击拉扯**（`retreatTactics`）：一次生物攻击把僵尸生命值打到最大值的
  20% 或以下，**或单次最终实伤达到最大生命值的 30%**（`retreatHeavyHitThreshold`）
  时，它会确定性地优先远离实际攻击者。撤退采用两个并列终止条件：与当前攻击者
  的**水平距离达到 5 格**（`retreatSafeDistance`）就提前重新参战；否则到达固定的
  **5 秒硬时限**（`retreatMaximumTicks=100`）也会结束。实伤按盾牌、护甲、附魔和
  吸收生命结算后的实际掉血计算；途中再次挨打只更新攻击者与逃跑方向，不延长从
  本次撤退开始计算的硬时限。撤退点通过原版陆地随机位置算法在背向攻击者的半平面
  寻找，速度倍率 `retreatSpeedModifier` 默认 1.5；
- **低血智能觅食**（`foodScavenging`，默认开启）：生命值严格低于一半且智力达到
  `foodMinimumIntelligence`（默认 6）的僵尸，每隔随机 2～4 秒获得一次搜索机会，
  IQ 6～10 的行动概率由 25% 递增到 65%。它只查询 12 格内的地面食物，并最多为
  价值排序为**附魔金苹果 > 金苹果 > 其余食物**，普通食物同层优先营养值更高者，
  腐肉仍是有效兜底；最多为前 4 个候选计算原版路径，没有可达食物时不接管 AI。抵达后只从物品堆拆出一份，
  播放该食物原版使用声音、粒子与抬手咀嚼动画，完成时立即按 `FOOD.nutrition`
  恢复等量生命值。主手有武器时优先用副手；两手都有装备时暂存副手物品，吃完、
  撤退打断或死亡前都会恢复。新生成僵尸不会预装或囤积食物；
- **地面武器优先换装**：普通僵尸每隔约 1～2.5 秒检查 12 格内的近战武器，最多为
  4 个候选计算路径。候选先按主手攻击伤害、附魔数量和耐久排序，再比较距离；空手或
  主手为腐肉等杂物时直接换装，已有武器时只接受严格升级。被替换的杂物/旧武器会完整
  掉回脚边，新武器沿用原版拾取装备的必掉落与持久化语义；水桶、岩浆桶和战术空桶不会
  被当作杂物。武器换装在同级战术中优先于觅食、采集和普通攻击；
- **高智力采集与地形战术**（`terrainTactics`，默认开启）：智力达到
  `terrainMinimumIntelligence`（默认 8）的普通僵尸锁定铁傀儡，或发现任意当前目标占据
  至少两格高且原版路径终点到不了其战斗层时，会在需要时搜索
  5 格内的泥土族（含草方块/灰化土/菌丝）、沙、泥、沙砾或黏土。它最多检查
  320 个局部方块、最多发起 4 次采集寻路，且必须在 3.1 格触及距离内以射线首先
  命中目标方块，因而不会隔墙挖掘。破坏过程按空手硬度持续 5～40 tick，包含挥手、
  敲击声和原版裂纹；每块只产生一个确定性建筑材料，不在地上制造随机重复掉落；
- 建筑材料进入独立的持久化单槽（`terrainBlockInventoryLimit` 默认 8、范围 3～16），
  不覆盖武器或盾牌；死亡时会掉出，转化为溺尸时则原子转移给新实体。集齐三块后，僵尸会选择距铁傀儡
  约 2.4～4.25 格、地基完整且上方无实体/流体/方块实体的位置，像玩家一样连续跳起
  向脚下放置三块。站稳后通过受武器攻击速度约束的俯身攻击打击下方铁傀儡；三格
  高度让双方碰撞箱分离，铁傀儡的原版近战范围失效。途中被撤退等高优先级行为打断
  时会回收一、两格半成品柱，完成的立柱保留。整个功能严格服从 `mobGriefing`；
- 对玩家或其他高处目标，僵尸只在水平 6 格内启动，并只检查目标柱四个正交邻格和四个
  对角邻格；正交格优先，再按行走距离排序，最多做 8 次寻路。这样完成后的柱位必在目标
  一格邻域，抵达同一战斗层即可进入原版近战范围，不会再在两三格外搭“同高但打不到”的
  偏柱。所需高度按真实高差向上取整，最高 4 格；
- 若目标直接站在泥土、沙、泥、沙砾或黏土等空手可破坏基础方块上，高智力僵尸还可能先
  走到 3.1 格真实触及位置，挖掉目标脚下唯一一格让其下落；默认 IQ 8/9/10 的选择概率为
  35%/50%/65%，其余情况走相邻垫高。拆柱沿用逐阶段裂纹、挥臂、敲击与最终碎屑，并保留
  方块正常掉落；石头、矿石、箱子、方块实体及需要工具的方块不会被选中。可正常绕行的
  山坡不改造，目标跳下时回收半成品，撤退过程不放置方块；
- **正式工程兵与随机技能**（`engineerSkills`，默认开启）：工程兵身份与“会使用地形战术”
  分离——所有达到门槛的高智力僵尸仍可采集、垫高和拆软柱，只有带持久化工程兵标记的少量
  个体才会运行技能调度器。普通自然候选必须是成年、智力达到地形战术门槛、双手为空且
  不是空袭兵；`engineerSpawnChance` 默认表示这类候选中的 8%，再按世界与区域难度缩放
  （区域难度拉满时，简单/普通/困难约为 6%/8%/10%）。自然生成的水桶辅助与岩浆骚扰
  变体会直接并入工程兵，并把智力提升到地形门槛；它们仍保留原有真实桶和反应式救火/
  受击支援，同时也能参加完整随机技能调度；
- 每项技能完成后，工程兵随机等待 120～200 tick（6～10 秒），再从**当时真正可执行**的
  四项技能中等概率选择一个：① **爆破装药**会走到目标脚下或八个邻格中的安全位置，真实放置
  TNT、换出打火石点燃，并生成 owner 为该工程兵、80 tick 引信的原版 `PrimedTnt`；随后
  以 1.35 倍速度后撤，最远跑 8 格或持续 60 tick。落点必须有完整地基、可替换、无流体/
  方块实体/生物碰撞，且 3.25 格内没有其他僵尸；未点燃时被高优先级行为打断会自动拆除
  本次装药。该技能同时服从 `engineerTntSkill`、`mobGriefing` 和 `tntExplodes`；
- ② **水流控制**与③ **岩浆控制**会在目标脚下及四个正交邻格选择已加载、位于世界边界内
  且可替换的真实落点，走进 4.25 格桶交互范围，取出对应桶并调用原版 `BucketItem` 投放，
  因此包含原版倒桶声音、挥手和流体事件。水保留 45～60 tick，岩浆保留 32～41 tick；
  工程兵先以 1.35 倍速度拉开，再返回源方块通过真实 `BucketPickup` 收走。源类型、坐标与
  最早回收时刻会随实体存档；被着火求生/受击撤退打断或服务器重启后仍优先完成回收，源被
  玩家提前取走则清除事务但不会伪造满桶。功能服从 `engineerFluidSkills` 与 `mobGriefing`；
- ④ **打火石点燃**只选择尚未着火且可达的当前目标。工程兵进入约 2.6 格近身范围并保持
  真实视线，抬起打火石等待 8 tick 后挥手、播放原版打火石声和火焰粒子，直接点燃目标
  5 秒；目标移动或遮挡时会继续追近而非隔墙点火，功能由 `engineerIgnitionSkill` 控制。
  临时 TNT、桶、空桶与打火石不会覆盖真实武器；技能打断、死亡、关服和恰逢自动存档时均
  恢复原装备。着火求生和受击撤退优先级更高，必要时可抢占工程技能；
- **火焰与日光生存**（沿用兼容字段 `sunlightSurvival`，默认开启）：任何真正处于着火
  状态的僵尸都会以优先级 0 暂停战斗，在半径 12 格内按同心方环寻找可进入的水体；每轮
  最多建立 8 条原版岸边路径，抵达稳定岸格后再用 `MoveControl` 跨入水中，避免原版陆地
  导航把水本身判为不可站立。搜索失败时按半秒节流；有日晒危险则转而寻阴影，否则释放
  移动控制并继续原有行为，不会每 tick 全图扫描；
- 着火成员还会向已有小队发出有界救火请求，由最近的满水桶队友接单。没有头部防护且在
  白天露天受晒时，另一只优先级 1 Goal 会按 3/6/9/12 格四圈寻找可达阴影，每轮最多尝试
  6 条路径。持水桶者优先调用原版倒水逻辑在脚下制造真实水源、播放桶声、挥手并灭火；
  该生存水源随实体存档，危险日光未解除前不会回收。最近 40 tick 内受到生物攻击只会
  抢占“仅日晒”阶段，已经着火时仍以灭火为先；
- **智能陷阱识别与跨沟**（`smartTraversal`，默认开启）：僵尸的陆地导航仍使用原版
  A*，但节点分类会额外读取门、栅栏门、活板门等方块的通用 `OPEN` 属性和真实顶面碰撞；
  已打开且不再承重的机关上方直接标为不可落脚，关闭后仍按原版规则通行。若目标位于同层、
  正前方恰好是一格无承重沟槽且再前一格是两格净空的稳定落点，僵尸会停止导航，调用原版
  `jumpFromGround()` 产生真实跳跃弧线，并补充朝落点的水平动量；落点、高差或净空不安全时
  不会盲跳；
- **水桶/岩浆桶辅助兵**（`specialEquipment`，默认开启）：空手成年僵尸按基础
  4%/2% 概率携带水桶/岩浆桶，概率随世界与区域难度略增。默认掉落率
  `specialEquipmentDropChance=0.085`，与原版 Mob 装备槽一致并可配置。工具兵在小队中
  获得“辅助兵”职位，并在自己的 Goal 接管移动时继续提交 O(1) 小队心跳。每只水桶兵
  都会保留已有合法靴子或补上铁靴，并保证附有仅适用于靴子的**深海探索者 III**；导航器
  同时允许浮水，使其能穿过自己铺开的水并返回源方块；
- 水桶兵平时保持约 4.5～8 格支援距离。自己或队友被当前战斗敌人攻击时，由伤害事件向所在
  小队做一次有界广播，它才把水放到敌人脚下或追击路线；岩浆兵主动寻找当前合法目标脚下
  及四个相邻格的可替换位置，跳过被友军实际占用的格子后投放岩浆并迅速拉开。因此它们既能
  对付生存玩家，也能响应铁傀儡、村民等原版僵尸会锁定的生物；创造/旁观玩家仍不属于原版合法目标。
  投放调用原版 `BucketItem.emptyContents`，会播放对应的倒水/倒岩浆声并同步挥手动画。水约 2.25～3 秒、岩浆约
  1.6～2.1 秒后，僵尸会回到源方块 4.25 格交互范围内用真实 `BucketPickup` 收回，
  随后进入冷却。投放位置、桶类型、回收时刻会随实体存档；玩家提前收走源方块时，
  僵尸保留空桶、即时失去辅助身份并恢复普通攻击。已投放事务即使配置热关闭也会先清理；
- 水桶兵进入低血/重伤撤退时，会先在自己脚下、敌我之间及两侧依次尝试合法水幕；起步格
  不可放置则每 10 tick 随新位置重试，成功后真实空桶会自然终止尝试。小队成员着火时，
  协调器仅遍历该队（默认最多 20）并选择最近的一只满水桶兵；它忽略普通投放冷却，走到
  4.25 格桶交互范围后优先把水倒在队友脚下，随后仍走同一套拉开、回收和丢失降级事务；
- 可选的**武装小队**系统（`armedSquads`，默认关闭）：僵尸持械概率随世界
  难度提升（简单/普通/困难默认 10%/30%/**85%**——困难模式一般僵尸都持械，
  材质从木到铁含 26.x 铜器），发放剑与斧：斧手正面破盾、剑手包抄加速，
  兵种会影响职位分配。武装系统不发矛——26.x 的矛由原版专属突刺 Goal 接管，
  与小队协同互斥；
- **持矛僵尸空袭**（`spearAirAssault`，默认开启）：原版自然生成的普通持矛僵尸会
  自动换上鞘翅，并在副手获得 `16～64` 枚烟花；所有难度使用相同上下限，但分布随
  难度向高弹量偏移。它们有弹药时不进行地面攻击，而是寻找有完整地基、六格净空且
  能看见天空的起飞点；起跳后先把机头直接抬到约 `-75°`，让第一枚火箭近乎垂直拔高，
  再调用原版通用滑翔物理并生成真实附着式
  `FireworkRocketEntity` 推进。专用烟花效率 `spearRocketEfficiency` 默认 `0.5`，
  稳定推进速度约为原版的一半；每枚发射物携带服务端选定值并同步客户端，不改变玩家烟花；
- 空袭状态机按“寻找起飞点 → 近垂直拔高 → 短盘旋 → 举矛蓄力 → 穿越目标 →
  拉起 → 再次短盘旋”循环。每轮基础盘旋仅 `24～40 tick`（约 1.2～2 秒），制定
  `1～2` 枚烟花的推进预算，两枚之间随机间隔 `32～44 tick`（约 1.6～2.2 秒）；即使
  视线、距离或第二枚烟花条件未完成，也会在 `72 tick` 内强制转入攻击准备，不再无限绕圈。
  低速蓄力会开放一次攻击助推，爬升和恢复阶段也各自最多只允许一次低空失速救援，不再
  按速度阈值连续喷射。无目标时，即使走台阶产生一个 tick 的离地，也不会切换
  滑翔姿态。铁矛原版需要 12 tick 才进入动能起伤窗口，所以僵尸会先在约
  10 格外举矛完成准备，再冲向目标；碰撞检测、速度门槛、伤害、击退、耐久和命中声
  全部继续走原版 `KineticWeapon` 管线，没有额外伪造伤害。最后一枚火箭可以完成
  当前攻击航次；弹尽或目标失效后会主动压低航向并着陆，落地后才恢复原版地面长矛
  突刺。客户端同时补齐水平飞行机身、展开鞘翅和双手举矛姿势；
- **智能武器战斗**（`weaponCombatTactics`，默认开启）作用于所有普通持剑/斧僵尸，
  不要求装备来自武装小队。它们命中后先短促后撤侧移，再沿约 2.8 格圆弧周旋，
  武器冷却完成才重新接近；冷却由物品 `ATTACK_SPEED` 计算，例如木/石/铜斧
  25 tick、铁斧 23 tick、钻石/下界合金斧 20 tick、剑 13 tick。斧手有平地与
  视线时会先建立 1.8～3.3 格起跳距离，仅在下落阶段命中并获得玩家同款 1.5 倍
  暴击与粒子/声音；水中或明显高低差会立即普通挥击，狭窄地形连续 30 tick 无法
  建立起跳窗口后也会降级。
  剑手只执行普通地面攻击，不跳劈；
- 武装小队还会产出**盾卫僵尸**（`armedShieldChance`，持械者额外配盾，普通
  减半/困难全额）：敌人进入 6 格交战带时优先举盾推进，进入近战距离后停步守候
  随机 12～28 tick（0.6～1.4 秒）。这期间敌人的攻击被盾牌完全挡住后，盾卫会继续
  举盾随机等待 2～4 tick，再明确放盾反击；敌人一直不出手，则在观察期结束且武器
  CD 就绪时主动放盾试探一次。攻击窗口最多 10 tick，攻击与防御互斥；一次挥击后
  保持放盾收招 2～4 tick 才重新举盾，目标躲开则窗口到期收招，不会裸奔追击。
  格挡走原版正面判定；客户端采用玩家同款胸前 `BLOCK` 姿势。原版的盾牌禁用与
  耐久损耗只对玩家生效，因此本 Mod 补了对称机制：**任何用斧头的攻击都会先打掉
  僵尸的盾**并使其短暂无法重举（时长同 `armedShieldBreakSeconds`），当次斧击
  伤害照常结算。持盾者优先被派往正面施压位；撤退 Goal 仍拥有更高优先级。

当前不会改造尸壳、溺尸、僵尸村民等僵尸变种。详细设计见
[ARCHITECTURE_PROPOSAL.md](ARCHITECTURE_PROPOSAL.md)。

## 骷髅首板已经会做什么

- 原版普通持弓骷髅会把 `RangedBowAttackGoal` 换成 `SmartSkeletonBowAttackGoal`；换成近战武器时
  仍由原版 `meleeGoal` 接管。总开关或 `skeletonAiEnabled` 关闭后，新 Goal 的完整生命周期
  直接委托给原版实现，不会让两个 MOVE/LOOK Goal 同时争抢控制权；
- **贴脸强制脱离**（`skeletonEmergencyDisengage`）：玩家进入偏好射程的 60%（默认 6 格）时，
  独立的 `SkeletonEmergencyDisengageGoal` 以移动优先级 1 抢占弓术、避日和避狼行为，立即取消
  当前拉弓并以 1.4 倍速度寻找真实后撤路径。它采用 60% 触发、90%（默认 9 格）结束的双阈值，
  所以不会在六格边缘反复启停；寻路至多每六 tick 更新一次，堵路时会面向玩家左右换向后撤。
  单次接管最长 80 tick，仍被堵住时会留出 20 tick 给弓术 Goal 边退边反击，再允许下一轮强制脱离；
- **距离分带与持续走位**：`skeletonPreferredRange` 默认 10 格。目标进入其约 60%（6 格）以内时，
  非玩家目标或强制脱离的反击窗口仍由弓术 Goal 通过 `DefaultRandomPos.getPosAway` 以 1.25 倍速度
  后撤；视线丢失或距离超过约 135%（13.5 格）时重新接敌，其余区域从第一个战斗 tick 起持续
  左右侧移，不再像原版那样原地观察 20 tick 才开始走位。侧移方向每 16～36 tick 才可能变化，
  盾牌目标会获得更强的横向绕射倾向；
- **局部来箭闪避**（`skeletonProjectileDodging`）：每三 tick 只查询自身七格内的箭，并用相对位置、
  箭速和最近交会时间判断轨迹。仅当箭预计在八 tick 内穿过 1.15 格安全半径时，执行 7～10 tick
  的随机侧闪；飞离中的箭、横向明显射偏的箭和八 tick 外的远箭都不会触发。查询走原版局部实体
  分区，不扫描全世界投射物；
- **移动目标预判**（`skeletonPredictiveAim`）：在原版箭速、竖直抛物线和难度散布全部保留的前提下，
  根据目标水平速度加入有限提前量。预测最多向前八 tick、最多三格，默认强度 65%，并按简单 65%、
  普通 82%、困难 100% 再缩放，因此困难模式更会预判但依然保留随机误差。拉弓仍需 20 tick，
  普通/困难射击间隔仍以原版 40/20 tick 为基准，只增加 ±4 tick 个体抖动来避免整齐齐射；
- `/mtn status` 会额外显示骷髅弓术/强制脱离 Goal 安装数、强制脱离、普通近身撤退、来箭闪避、
  射击和实际使用提前量的累计次数。

当前首板只改造 `minecraft:skeleton` 的持弓形态；流浪者、沼骸、凋灵骷髅及其他变种继续使用
各自的原版攻击间隔，后续再按兵种分别设计，而不是直接套用同一套参数。

## 安装

1. 安装 Minecraft Java 26.1.2 对应的 Fabric Loader。
2. 把 Fabric API 和本模组 JAR 放进实例的 `mods` 目录。
3. 如需图形化配置，再在客户端安装 Mod Menu 和 Cloth Config；不使用配置页时无需安装。
4. 单人游戏安装在客户端；专用服务器可只安装本模组和 Fabric API，无需安装上述两个客户端配置依赖。

首次启动后会生成：

```text
config/mobsthinknow.json
```

单人游戏或本地服务器可从 Mod Menu 打开配置页，调整单支小队上限、150% 撤退速度、
觅食、地形战术、工程兵技能/生成率/TNT/流体/点燃、日光生存、智能通行、持矛空袭、僵尸烟花推进
效率、个体属性、特殊桶兵生成率与掉落率，以及骷髅贴脸强制脱离、偏好射程、来箭闪避和移动预判
等参数。单支僵尸小队上限范围为 `4～100`，默认值为 `20`。
专用服务器请直接修改配置文件，随后执行
`/mtn reload`。使用 `/mtn status` 可查看是否启用、已安装
Goal 数、战术决策数、活跃小队、首领选举/换届、候选检查、寻路失败数以及累计
采集/放置方块、立柱俯击、流体投放/回收/丢失、工程兵 TNT/水/岩浆/点燃次数，以及骷髅强制脱离、
普通撤退、来箭闪避、射击和预判射击次数；
重载命令需要管理员权限。

管理员还可以执行 `/mtn spawnall`，在命令源面前一次排出 3×3 的九种当前战术样本：
空手、剑手、斧手、剑盾、斧盾、工程兵、水桶辅助、岩浆骚扰和持矛空袭。它们使用
固定兵种名牌与合格智力值，但速度、生命、攻击等个体属性仍走真实出生流程；命令不会
改动服务器配置，所以盾卫、流体、地形、工程技能与空袭行为仍分别服从当前功能开关。
其中 `builder`、`water_support` 和 `lava_harasser` 都会被确定性标记为正式工程兵：前者
预装满材料槽，后二者保留真实桶以演示反应式支援；另外六只会明确清除该标记。附近空间
不足时整批取消，避免生成残缺阵容。

使用 `/mtn spawn` 可以查看兵种与批量语法，随后执行 `/mtn spawn <类型> [数量]`，在命令源
正前方安全地生成指定兵种；`<类型>` 支持 Tab 补全，省略数量时保持原行为、默认生成一只，
数量参数允许 `1～100`：

```text
unarmed        swordsman       axeman
sword_shield   axe_shield      builder
water_support  lava_harasser   air_assault
```

例如 `/mtn spawn air_assault` 只生成一只持矛空袭兵，`/mtn spawn water_support 12` 会生成
十二只带真实水桶的工程兵变体，`/mtn spawn builder 20` 则生成二十只 IQ 10、材料槽已满的
通用工程兵；两者都可以随机使用 TNT、水、岩浆和打火石。批量实体会以三格间距排成近似
正方形阵型，并先统一检查全部落点和创建结果；空间不足或中途加入世界失败时整批取消，
不会留下少于请求数量的残阵。该指令同样需要管理员权限，并保留当前配置开关的约束。

## Alpha 限制

- 侧袭点目前使用轻量几何计算，复杂建筑和高低差仍由原版寻路决定；
- 智力会持久化，小队、首领和命令是临时战斗状态，不持久化到存档；
- 职业名牌使用本模组语言键；未安装本模组的原版客户端会显示英文回退文本；
- 材料槽只保留一种方块类型，完整立柱与玩家追击墙不会自动拆除。后续再扩展
  跨障碍搭桥、拆门、混合材料和战后清理；
- 持矛空袭目前只寻找半径 7 格内的露天起飞点；长期封闭洞穴中的持矛僵尸会保留
  火箭并等待出现可用起飞空间，不会为了强行出手切回地面攻击；
- 工程兵的战术 TNT 使用原版爆炸和 4 秒引信；当三个开关/规则均开启时会真实伤害生物并
  改造可破坏地形。随机技能使用的 TNT、水桶、岩浆桶与打火石目前是职业资源而非库存，
  不会耗尽；可分别关闭 `engineerTntSkill`、`engineerFluidSkills` 或
  `engineerIgnitionSkill`；
- 尚未完成大规模实体压力测试和网易环境适配验证；
- 配置字段和数值在正式版前可能调整。
